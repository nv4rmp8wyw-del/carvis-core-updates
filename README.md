# CARVIS CORE – Downloads

Dieses **öffentliche Repository dient ausschließlich als Download-Kanal** für geprüfte Windows-Installer und Updates von CARVIS CORE.

**Der Quellcode von CARVIS CORE ist privat und wird hier nicht veröffentlicht.**

## Updates

Die Windows-Anwendung soll neue geprüfte Releases ohne GitHub-Anmeldung finden und installieren können. Solange auf dieser Seite kein Release bereitsteht, gibt es noch kein freigegebenes öffentliches Update.

Jeder freigegebene Release enthält:
- einen Windows-Installer (`CARVIS-CORE_<version>_x64-setup.exe`),
- `SHA256SUMS.txt` zum Prüfen der Dateiintegrität,
- kurze Versionshinweise und, wenn verfügbar, überprüfbare Signatur/Provenienz.

**Sicherheit:** Dateien werden erst nach bestandenen Build-, Migrations-, Sicherheits- und Installationsprüfungen veröffentlicht. SHA-256 allein beweist nicht die Vertrauenswürdigkeit des Herausgebers.

Keine Quellcodedateien, Entwicklungstokens oder Nutzerinformationen in diesem Repository hochladen.
